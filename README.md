# مغامرة الإنجليزي – الصف السادس (الوحدة الأولى)

لعبة تعليمية تفاعلية لمنهج اللغة الإنجليزية للصف السادس (السودان)، الوحدة الأولى.

**العب الآن:** https://aljompolaty.github.io/english-grade6-game/

## المحتوى
- 8 دروس مع صفحات الكتاب، وتحديات، ولعبة رتّب الجمل، ولعبة عبور النهر.
- مراجعة متباعدة للأخطاء، وإتقان حسب المهارة، وفتح الدروس تدريجياً.
- كل الجمل مسجّلة بأصوات احترافية، والشخصيات تتكلم بأصواتها.
- شرح صوتي لكل درس باللغة العربية.
- مشاهد حوار بأصوات الشخصيات، ولعب أدوار مع تسجيل صوت الطالب.
- أناشيد الكتاب ملحّنة.

## التشغيل محلياً
افتح `index.html` في المتصفح، مع إبقاء مجلد `audio` بجانبه.

الأصوات والموسيقى مولّدة بـ ElevenLabs.

## التثبيت على أندرويد
1. افتح الرابط في متصفح Chrome على الهاتف.
2. اضغط زر **📲 ثبّت اللعبة على جهازك** داخل اللعبة، أو من قائمة Chrome (⋮) اختر **تثبيت التطبيق**.
3. تظهر أيقونة اللعبة على الشاشة الرئيسية، وتعمل بعد ذلك حتى من دون إنترنت.
